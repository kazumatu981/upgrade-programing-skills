# 単体テスト仕様

## `Dice`

### constructor

- `counterId` に存在するIDを指定する
    - インスタンスが生成することを確認する
- `counterId` に存在しないIDを指定する
    - 例外が発生することを確認する

### `value` プロパティ

- `string`型を設定する
    - 例外が発生する
- プロパティを設定する
    - `0` を設定: 例外が可能
    - `1` を設定: 設定が可能
    - `-1` を設定: 例外が発生
    - `6` を設定: 設定が可能
    - `7` を設定: 例外が発生

### `start()` メソッド

- `state` が `stopped` の場合:
    - `started`イベントが発生
    - ダイスが回り始める
    - `changed` が発生し続ける
- `state` が `started` の場合:
    - 何も起きない
- `state` が `stopping` の場合:
    - 何も起きない

### `stop()` メソッド

- `state` が `stopped` の場合:
    - なにも起きない
- `state` が `started` の場合:
    - `stopping`のイベントが発生
    - ダイスがゆっくり止まり始める
    - 少しの間`changed` が発生し続ける
    - 少し経つと `stopping`が発生
- `state` が `stopping` の場合:
    - なにも起きない
