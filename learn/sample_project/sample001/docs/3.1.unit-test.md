# 単体テスト仕様書

## M1.カウンタ部品

### constructor

- `counterId` に存在するIDを指定する
    - インスタンスが生成することを確認する
- `counterId` に存在しないIDを指定する
    - 例外が発生することを確認する

### `value` プロパティ

- `string`型を設定する
    - 例外が発生する
- プロパティを設定する
    - `0` を設定: 設定が可能
    - `1` を設定: 設定が可能
    - `-1` を設定: 例外が発生
    - `99` を設定: 設定が可能
    - `100` を設定: 例外が発生

### `maximum` プロパティ

- 参照すると `99` が返却される

### `minimum` プロパティ

- 参照すると `0` が返却される

### `increment()` メソッド

- `5` のとき実行すると`6`になる
- `99` のとき実行すると例外が発生する

### `decrement()` メソッド

- `5` のとき実行すると`4`になる
- `0` のとき実行すると例外が発生する

### `change` イベント

- `value` で値を設定するとイベントが発生する
- `increment()`実行時にイベントが発生する
- `decrement()` 実行時にイベントが発生する

## M2.コントローラ部品

### constructor

- `incrementButtonId`/ `decrementButtonId`ともに存在するDOMを指定
    - エラーなし
- `incrementButtonId`に存在しないIDを指定する
    - 例外発生
- `decrementButtonId`に存在しないIDを指定する
    - 例外発生

### enableIncrement プロパティ

- string型を指定する
    - 例外が発生する
- `true` を指定する
    - クリックできる状態
    - CSSクラスが、diableButtonからenableButtonに変更される
- `false` を指定する
    - クリックできる状態
    - CSSクラスが、enableButtonからdisableButtonに変更される

### enableDecrement プロパティ

- string型を指定する
    - 例外が発生する
- `true` を指定する
    - クリックできる状態
    - CSSクラスが、diableButtonからenableButtonに変更される
- `false` を指定する
    - クリックできる状態
    - CSSクラスが、enableButtonからdisableButtonに変更される

### click_increment イベント

- プラスボタンをクリックしたらイベントが発生する

### click_decrement イベント

- マイナスボタンをクリックしたらイベントが発生する
