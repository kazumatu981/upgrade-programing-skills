# 部品設計書: M2.コントローラ部品: `Controller`

99カウンタのうち、M2.コントローラ部品 を表すクラス。

## 機能概要

- プラスボタンとマイナスボタンの活性/非活性を変更する
    - `enableIncrement`/`enableDecrement` プロパティ
- ボタンクリックのイベント発生
    - `click_increment`/`click_decrement` イベント

---

## インタフェース

### `constructor(incrementButtonId, decrementButtonId)`

`incrementButtonId`/ `decrementButtonId` をそれぞれ「プラスボタン」「マイナスボタン」としてインスタンスを生成する。

### プロパティ

| プロパティ名      | 概要                     |
| ----------------- | ------------------------ |
| `enableIncrement` | プラスボタンの活性状態   |
| `enableDecrement` | マイナスボタンの活性状態 |

活性状態は以下の通りとする

- `true`: 活性
- `false`: 非活性

### メソッド

なし

### イベント

| イベント名        | イベント                 | 引数             |
| ----------------- | ------------------------ | ---------------- |
| `click_increment` | プラスボタンをクリック   | このオブジェクト |
| `click_decrement` | マイナスボタンをクリック | このオブジェクト |

---

## 処理明細

### `constructor`

- `incrementButtonId`/ `decrementButtonId` を検索キーとしてDOM要素を検索し、クラスローカル変数に格納する。
- オブジェクトが見つからない場合は例外を発生させる。
- これらのボタンにマウスクリックのイベントで、`click_increment`/ `click_decrement` を発生するように設定する
- なお、イベント発生はボタンの活性状態を確認して発生させること

### `enableIncrement` / `enableDecrement` プロパティ

#### `set`

- ボタンの状態をクラスローカル変数に格納する。
- DOM要素のクラス(cssクラス名)に **クリックできる状態** / **クリックできない状態** を下記表に従って適切に設定すること

| プロパティの値 | 状態                     | 設定するクラス名 | 除外するクラス名 |
| -------------- | ------------------------ | ---------------- | ---------------- |
| `true`         | **クリックできる状態**   | `enableButton`   | `disableButton`  |
| `false`        | **クリックできない状態** | `disableButton`  | `enableButton`   |

#### `get`

- クラスローカル変数を返却する

### プライベートについて

今後、イベントの追加、`enableIncrement` / `enableDecrement` の内部実装(cssクラス名変更)が予想されるため、
クラスプライベート関数として以下の二つを共通化しておく。

| メソッド名                | 役割                       |
| ------------------------- | -------------------------- |
| `_registerButtonEvents()` | イベントを登録する         |
| `_setButtonState()`       | ボタンのスタイルを変更する |
